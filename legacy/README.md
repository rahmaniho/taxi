# تاکسی تلفنی کارن‌سافت — نسخهٔ ۵٫۰٫۰

سامانهٔ مدیریت و اتوماسیون آژانس تاکسی تلفنی، به‌صورت یک برنامهٔ تک‌صفحه‌ای (SPA) فارسی و راست‌به‌چپ که کاملاً در مرورگر اجرا می‌شود: صف انتظار و تخصیص راننده، مدیریت رانندگان و خودروها، مشترکین و بدهی، حسابداری راننده، گزارش‌ها و خروجی PDF.

* فایل اصلی: **`legacy/taxi.html`**
* بدون بک‌اند و بدون وابستگی بیرونی (هیچ CDN اجباری برای اجرا وجود ندارد)
* نصب‌پذیر به‌عنوان برنامه (PWA) و کارکرد آفلاین
* همهٔ تاریخ‌ها شمسی و همهٔ اعداد فارسی

---

## ۱) اجرای محلی

مرورگرها اجرای ES Modules و Service Worker را روی پروتکل `file://` محدود می‌کنند، پس برنامه را با یک وب‌سرور سادهٔ محلی باز کنید:

```bash
# ۱) دریافت مخزن
git clone https://github.com/rahmaniho/karen-soft.git
cd karen-soft

# ۲) اجرای یک وب‌سرور ساده روی پوشهٔ مخزن
python3 -m http.server 8080
#   یا:  npx serve .

# ۳) باز کردن برنامه
#      http://localhost:8080/legacy/taxi.html
```

گزینه‌های دیگر: افزونهٔ Live Server در VS Code، یا هر وب‌سرور دیگر (nginx/Apache). مسیر پوشه مهم نیست؛ همهٔ لینک‌های برنامه **نسبی** هستند و در ریشه یا زیرپوشه کار می‌کنند.

### ورود به برنامه

کاربران پیش‌فرض (در اولین اجرا ساخته می‌شوند):

| نقش | نام کاربری | رمز عبور |
|---|---|---|
| مدیر سامانه | `admin` | `admin123` |
| اپراتور | `operator` | `operator123` |
| حسابدار | `accountant` | `account123` |

> پس از اولین ورود، رمزها را از «کاربران و شیفت‌ها» یا منوی کاربر → «تغییر رمز عبور» عوض کنید.

داده‌های نمونه (راننده، مشترک، سفر، هزینه) به‌صورت آموزشی ساخته می‌شوند و با دکمهٔ «حذف داده‌های نمونه» در صفحهٔ پشتیبان‌گیری یا تنظیمات پاک می‌شوند.

## ۲) نصب به‌عنوان برنامه (PWA)

1. برنامه را در مرورگر باز کنید (اندروید: کروم / iOS: سافاری / دسکتاپ: کروم یا اج).
2. منوی مرورگر → «نصب برنامه» یا «افزودن به صفحهٔ اصلی». در تنظیمات برنامه هم دکمهٔ «نصب برنامه» وجود دارد.
3. پس از نصب، برنامه در حالت `standalone` و بدون نوار آدرس باز می‌شود و در حالت آفلاین هم کار می‌کند.

---

## ۳) آزمون‌ها

```bash
# آزمون داده و قواعد کاری (بدون نیاز به مرورگر)
node tests/smoke.mjs

# آزمون رابط کاربری (نیازمند jsdom)
npm i --no-save jsdom
node tests/dom-smoke.mjs
# یا با مسیر دلخواه:  JSDOM_PATH=/path/to/node_modules/jsdom node tests/dom-smoke.mjs
```

* `smoke.mjs`: ۱۰۹ بررسی — تقویم شمسی، اعتبارسنجی تلفن/کد ملی/پلاک، کرایهٔ شب و تعطیلات، چرخهٔ سفر، بدهی مشترک، تسویهٔ راننده، گزارش‌ها، نقش‌ها و شیفت، پشتیبان‌گیری.
* `dom-smoke.mjs`: ۶۳ بررسی — راه‌اندازی پوسته، ورود، رندر همهٔ صفحه‌ها، تم، سایدبار، مودال‌ها، تخصیص راننده، تقویم، جدول و دسترسی نقش‌ها.

## ۴) پشتیبان‌گیری و انتقال داده

* «پشتیبان‌گیری» → «دریافت فایل پشتیبان (.json)»: تمام داده‌ها در یک فایل.
* «بازیابی و ادغام»: افزودن/به‌روزرسانی رکوردهای فایل روی داده‌های فعلی.
* «جایگزینی کامل داده»: پاک کردن داده‌های فعلی و نشستن فایل پشتیبان به‌جای آن.
* برای انتقال به دستگاه دیگر، فقط همان فایل JSON را در دستگاه مقصد بازیابی کنید.

## ۶) نکات فنی

* **ذخیره‌سازی**: در این فاز `localStorage` (کلید `taxi_dispatch_db_v5`). لایهٔ داده آداپتور دارد؛ برای اتصال به **PocketBase** یا **Supabase** کافی است در «پشتیبان‌گیری → اتصال به سرویس ابری» آدرس و کلید را وارد کنید — رابط کاربری تغییری نمی‌خواهد.
* **مهاجرت**: داده‌های نسخهٔ قبلی (`taxi_dispatch_db_v4`) در اولین اجرا خودکار منتقل می‌شوند.
* **مرورگرها**: کروم/اج ۹۰+، فایرفاکس ۹۰+، سافاری ۱۵+ (روی iOS برای نصب PWA از سافاری استفاده کنید).
* **چاپ/PDF**: هر سند ابتدا پیش‌نمایش داده می‌شود؛ در پنجرهٔ چاپ مرورگر گزینهٔ «ذخیره به‌عنوان PDF» خروجی PDF می‌دهد.
* **دسترس‌پذیری**: رابط راست‌به‌چپ، ارقام فارسی، اندازه‌های لمسی مناسب موبایل و پشتیبانی از `prefers-reduced-motion`.
