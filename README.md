# کارن‌سافت · سامانه مدیریت تاکسی تلفنی

نسخهٔ آفلاین‌محور و تک‌صفحه‌ای کارن‌سافت با رابط فارسی/RTL، مدیریت سفر و صف انتظار، تخصیص راننده، حسابداری، چاپ با هویت بصری آژانس و قابلیت نصب PWA.

## فایل‌ها

- `taxi.html` — برنامهٔ کامل؛ HTML، CSS و JavaScript داخل یک فایل (کمتر از ۳۰۰ کیلوبایت)
- `sw.js` — Service Worker برای کش فایل‌های برنامه، آفلاین، به‌روزرسانی و لوگوی آژانس
- `manifest.json` — مشخصات PWA، آیکون‌ها و میان‌برها
- `icons/` — آیکون‌های PNG در اندازه‌های لازم؛ `brand.svg` طرح برداری آیکون پیش‌فرض است

> فایل لوگوی اختصاصی همراه مخزن ارائه نشده است؛ نشان پیش‌فرض کارن‌سافت در آیکون‌ها و رابط استفاده می‌شود. لوگوی آژانس را از صفحهٔ **تنظیمات ← هویت بصری آژانس** بارگذاری کنید. لوگو در مرورگر ذخیره و در سربرگ فاکتور، صورتحساب و رسید چاپی درج می‌شود.

## اجرای محلی

برای آزمایش رابط می‌توان فایل را مستقیم باز کرد؛ اما نصب PWA و Service Worker در `file://` فعال نمی‌شود. برای اجرای کامل، در ریشهٔ مخزن یک سرور محلی راه‌اندازی کنید:

```bash
python3 -m http.server 8000
```

سپس `http://localhost:8000/taxi.html` را باز کنید. مرورگرهای موبایل برای دسترسی به localhost رایانه ممکن است به HTTPS یا آدرس شبکهٔ رایانه نیاز داشته باشند.

## انتشار روی GitHub Pages

محتویات این پوشه را روی شاخهٔ انتشار GitHub Pages قرار دهید و نشانی `.../taxi.html` را باز کنید. HTTPS خودکار GitHub Pages برای نصب PWA لازم است. فایل‌ها و مسیرهای manifest، Service Worker و آیکون‌ها نسبی هستند و در انتشار زیرمسیر مخزن نیز کار می‌کنند.

## نصب

- **Android / Chrome:** از بنر «نصب برنامه» یا منوی مرورگر گزینهٔ نصب را بزنید.
- **Windows / macOS / Linux:** در Chrome یا Edge از آیکون نصب کنار نوار نشانی یا منوی مرورگر استفاده کنید.
- **iPhone / iPad:** در Safari گزینهٔ Share و سپس **Add to Home Screen** را انتخاب کنید.

پس از اولین بارگذاری آنلاین، HTML، manifest و آیکون‌ها کش می‌شوند. Chart.js، Font Awesome و فونت Vazirmatn نیز هنگام دسترسی آنلاین به‌صورت Cache-First ذخیره می‌شوند. داده‌های سفر بدون وابستگی به CDN در دسترس هستند.

## داده و حریم خصوصی

تمام اطلاعات در یک کلید `localStorage` با نام `taxi_db_v1` و فقط در مرورگر/دستگاه جاری نگهداری می‌شوند. برنامه سرور API، ردیابی زنده، نقشه یا همگام‌سازی بین اپراتورها ندارد. برای انتقال دستگاه، از صفحهٔ **پشتیبان‌گیری** فایل JSON دریافت و در دستگاه مقصد بازیابی کنید. بازیابی، داده‌های فعلی همان مرورگر را جایگزین می‌کند.

پروفایل اپراتور و شیفت برای ثبت رویدادها و گزارش‌گیری محلی است؛ ورود با رمز یا احراز هویت سازمانی محسوب نمی‌شود. برای استفادهٔ چندکاربره و کنترل دسترسی واقعی، اتصال به API امن لازم است.

## گردش‌کار پیشنهادی

1. در تنظیمات، نام، تلفن، آدرس، تعرفه و لوگوی شرکت را وارد کنید.
2. راننده و خودرو، آدرس‌های پرتکرار و مشترکین را ثبت کنید.
3. سفر جدید بسازید؛ مبدأ/مقصد، روش پرداخت، تاریخ شمسی و در صورت نیاز مسافت تقریبی را وارد کنید.
4. از صف انتظار رانندهٔ پیشنهادی را تخصیص دهید، سفر را شروع و سپس تکمیل کنید.
5. دریافت مشترک، پرداخت راننده و هزینه‌های آژانس را ثبت کنید؛ صورتحساب را پیش‌نمایش/چاپ کنید.
6. به‌طور منظم نسخهٔ پشتیبان بگیرید.

برآورد کرایه بدون نقشه و بر پایهٔ کرایهٔ پایه، مسافت تقریبی، ضریب شب و جمعه است؛ اپراتور می‌تواند کرایه را دستی تغییر دهد.

## بررسی‌های سریع

- HTML کمتر از ۳۰۰ کیلوبایت است و اسکریپت درون‌خطی با Node.js از نظر نحوی بررسی‌پذیر است.
- `manifest.json` باید JSON معتبر باشد و همهٔ مسیرهای معرفی‌شده در آن به PNG موجود اشاره کنند.
- Service Worker و نصب PWA را با `localhost` یا یک نشانی HTTPS آزمایش کنید؛ برای مشاهدهٔ حالت آفلاین پس از نصب، بارگذاری آنلاین اولیه را کامل کنید.
- چاپ از پیش‌نمایش برنامه در یک iframe مخفی انجام می‌شود. برای PDF، مقصد «ذخیره به‌صورت PDF» را در پنجرهٔ چاپ مرورگر انتخاب کنید.
